# Doctor Who na Veia! 🎬

Um site dedicado à série **Doctor Who**, apresentando temporadas clássicas, spin-offs e especiais. Desenvolvido com HTML, CSS e design moderno com efeitos visuais futuristas.

## 📋 Sobre o Projeto

Este site é um tributo à série de ficção científica **Doctor Who**, onde você encontra informações sobre:

- **Temporadas Clássicas**: Doctor Who 1963, 2005, Flux e 2024
- **Spin-offs**: K9 And Company, TorchWood, K9, The Sarah Jane Adventures e Class
- **Especiais**: Conteúdo adicional da série

O design apresenta uma temática futurista com gradientes cibernéticos, efeitos de brilho e animações dinâmicas.

## 🚀 Como Usar

### Clonar do GitHub

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/doctor-who-na-veia.git

# Entre no diretório
cd doctor-who-na-veia

# Abra o arquivo no navegador
start index.html
# ou
open index.html  # macOS
xdg-open index.html  # Linux
```

### Estrutura do Projeto

```
doctor-who-na-veia/
├── index.html          # Arquivo principal HTML
├── style.css          # Folha de estilos
├── README.md          # Este arquivo
└── src/
    ├── classicos/     # Imagens das temporadas clássicas
    ├── especiais/     # Imagens de especiais
    └── spin-offs/     # Imagens dos spin-offs
```
